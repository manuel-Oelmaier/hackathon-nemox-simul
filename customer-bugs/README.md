# Possible customer bugs — app.nemox.ai

Ten quoting bugs a freight forwarder would actually report. Rebuilt from the public product (inbox quoting, rate sheets, live platforms, customer margins, TMS write-back) and from the failure modes already noted in this repo: bad price, bad timing, bad route, and a quote the rep will not send.

These are not copies of private Slack, PostHog, or support tickets.

Each file is one report: date, who reported it, severity, tags, what they said, and the freight detail a developer needs.
